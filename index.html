Chưa có tên miền nào

Thêm tên miền để bắt đầu tạo địa chỉ email

📋 Hướng dẫn cấu hình DNS

1
Thêm bản ghi MX

Trỏ MX record về IP server của bạn (priority: 10)

MX @ mail.yourdomain.com 10
2
Thêm bản ghi A/AAAA

Trỏ mail subdomain về IP server

A mail [YOUR_SERVER_IP]
3
Cấu hình SPF (khuyến nghị)

Cho phép server gửi thư thay mặt domain

TXT @ "v=spf1 mx ~all"
4
Mở port SMTP

Mở port 25 (SMTP) trên firewall/VPS của bạn

ufw allow 25/tcp
